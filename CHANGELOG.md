# Changelog

All notable changes to this project. Each entry links to its full per-version file in [changelog/](changelog/).

## [0.1.2](changelog/0.1.x/0.1.2.md) — 2026-10-01

Feature filters GeoNames can never match now fail before the request, reverse geocoding gains an opt-in coastal buffer, and country filters accept alpha-3 and numeric codes.

## [0.1.1](changelog/0.1.x/0.1.1.md) — 2026-10-01

First published release — eight GeoNames tools for place search, full place records, admin hierarchies and children, reverse geocoding, postal codes, country facts, and reference vocabulary, spending the server's GeoNames account or the caller's own.

## [0.1.0](changelog/0.1.x/0.1.0.md) — 2026-09-29

Unpublished project scaffold from @cyanheads/mcp-ts-core — no package was released under this version.
